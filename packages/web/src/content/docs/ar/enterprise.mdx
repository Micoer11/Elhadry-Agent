Elhadry Agent Enterprise مخصص للمؤسسات التي تريد التأكد من أن الشيفرة والبيانات لا تغادر بنيتها التحتية مطلقا. ويمكن تحقيق ذلك عبر استخدام إعدادات مركزية تتكامل مع SSO وبوابة AI الداخلية لديك.

:::note
لا يقوم Elhadry Agent بتخزين أي من شيفرتك أو بيانات السياق.
:::

لبدء استخدام Elhadry Agent Enterprise:

1. أجرِ تجربة داخلية مع فريقك.
2. **<a href={email}>اتصل بنا</a>** لمناقشة التسعير وخيارات التنفيذ.

---

## تجربة

Elhadry Agent مفتوح المصدر ولا يخزن أي من شيفرتك أو بيانات السياق، لذا يمكن للمطورين لديك ببساطة [البدء](/docs/) وإجراء تجربة.

---

### التعامل مع البيانات

**لا يقوم Elhadry Agent بتخزين شيفرتك أو بيانات السياق.** تتم جميع المعالجة محليا أو عبر استدعاءات API مباشرة إلى مزود AI لديك.

وهذا يعني أنه طالما أنك تستخدم مزودا تثق به، أو بوابة AI داخلية، يمكنك استخدام Elhadry Agent بأمان.

---

### ملكية الشيفرة

**أنت تملك كل الشيفرة التي ينتجها Elhadry Agent.** لا توجد قيود ترخيص أو مطالبات بالملكية.

---

## التسعير

نستخدم نموذج تسعير لكل مقعد في Elhadry Agent Enterprise. إذا كانت لديك بوابة LLM خاصة بك، فلن نفرض رسوما على الرموز (tokens) المستخدمة. لمزيد من التفاصيل حول التسعير وخيارات التنفيذ، **<a href={email}>اتصل بنا</a>**.

## النشر

بعد إكمال التجربة وعندما تكون جاهزا لاستخدام Elhadry Agent داخل مؤسستك، يمكنك **<a href={email}>الاتصال بنا</a>** لمناقشة التسعير وخيارات التنفيذ.

---

### الإعدادات المركزية

يمكننا إعداد Elhadry Agent لاستخدام إعدادات مركزية واحدة لكامل مؤسستك.

يمكن لهذه الإعدادات المركزية أن تتكامل مع مزود SSO لديك، وتضمن أن جميع المستخدمين يصلون فقط إلى بوابة AI الداخلية لديك.

---

### تكامل SSO

عبر الإعدادات المركزية، يمكن لـ Elhadry Agent التكامل مع مزود SSO في مؤسستك لأغراض المصادقة.

يتيح ذلك لـ Elhadry Agent الحصول على بيانات الاعتماد لبوابة AI الداخلية لديك عبر نظام إدارة الهوية الحالي لديك.

---

### بوابة AI الداخلية

مع الإعدادات المركزية، يمكن أيضا تهيئة Elhadry Agent لاستخدام بوابة AI الداخلية لديك فقط.

يمكنك أيضا تعطيل جميع مزودي AI الآخرين، لضمان مرور جميع الطلبات عبر البنية التحتية المعتمدة في مؤسستك.

---

### الاستضافة الذاتية

بينما نوصي بتعطيل صفحات المشاركة لضمان ألا تغادر بياناتك مؤسستك مطلقا، يمكننا أيضا مساعدتك على استضافتها ذاتيا على بنيتك التحتية.

هذا موجود حاليا على خارطة طريقنا. إذا كنت مهتما، **<a href={email}>أخبرنا</a>**.

<details>
<summary>هل يمكننا استخدام سجل NPM خاص بنا؟</summary>

يدعم Elhadry Agent سجلات npm الخاصة عبر دعم Bun الأصلي لملف `.npmrc`. إذا كانت مؤسستك تستخدم سجلا خاصا مثل JFrog Artifactory أو Nexus أو ما شابه ذلك، فتأكد من مصادقة المطورين قبل تشغيل Elhadry Agent.

لإعداد المصادقة مع السجل الخاص بك:

```bash
npm login --registry=https://your-company.jfrog.io/api/npm/npm-virtual/
```

سيؤدي ذلك إلى إنشاء `~/.npmrc` مع تفاصيل المصادقة. سيلتقط Elhadry Agent هذا تلقائيا.

:::caution
يجب أن تكون مسجلا الدخول إلى السجل الخاص قبل تشغيل Elhadry Agent.
:::

بدلا من ذلك، يمكنك تهيئة ملف `.npmrc` يدويا:

```bash title="~/.npmrc"
registry=https://your-company.jfrog.io/api/npm/npm-virtual/
//your-company.jfrog.io/api/npm/npm-virtual/:_authToken=${NPM_AUTH_TOKEN}
```

يجب أن يكون المطورون مسجلين الدخول إلى السجل الخاص قبل تشغيل Elhadry Agent لضمان إمكانية تثبيت الحزم من سجل مؤسستك.

</details>
